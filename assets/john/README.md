# assets/john/

Header images for the John devotional series (`../john/john-01-....html` through `john-21-....html`).

Naming convention: `john-01-header.jpg`, `john-02-header.jpg`, ... matching each chapter's number.

Once an image lands here, ask Claude to wire it into that chapter's page — it'll reference it as `../assets/john/john-XX-header.jpg` from within the `john/` folder.
